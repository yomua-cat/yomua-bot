# 文档索引

这里维护当前代码的行为与使用方式。每份文档只负责一个主题，验证日期、未完成能力与已确认问题集中维护在[项目现状](status.md)。

| 文档 | 用途 |
| --- | --- |
| [架构](architecture.md) | 分层、消息链路、状态边界和后台任务 |
| [配置](configuration.md) | 初始化、字段、LLM 路由与配置示例 |
| [部署运维](deployment.md) | 构建、启动、检查、关停、备份与升级 |
| [CLI](cli.md) | 主程序工具、控制客户端和命令限制 |
| [插件](plugins.md) | 插件布局、进程生命周期、IPC 与权限 |
| [项目现状](status.md) | 验证基线、已确认问题和后续整顿顺序 |
| [使用验收指南](verification-guide.md) | 按功能场景逐项检查当前实现 |
| [贡献规范](../CONTRIBUTING.md) | 修改边界、检查命令与协作要求 |

新用户先看根目录[README](../README.md)，部署时结合配置和运维文档。开发时先看架构和项目现状，再沿文中的源码入口阅读实现。
